## Documentation

The added functionaly works as follows.

Sidebar:
There are buttons under the PyTest! label that run all the different tests. The labels of the buttons describe what they do.

Main Body:
Under the additional tools label are the 3 added features. The first is a gui that tells you the number of completed, total, and incomplete tasts. The second is a button that you can press that marks all your tasks as complete. The third you can enter 2 dates and it gives you all the tasks that are due within those dates.
